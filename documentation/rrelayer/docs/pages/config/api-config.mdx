# API Config

This controls the API listener alongside its basic authentication details. TCP
remains the default transport. Unix systems can instead expose the API through
an owner-only Unix domain socket.

## Fields

### host - optional defaults to localhost

The host the API will try to start up from, you may need to override it if you want to expose the api to a wider network

```yaml [rrelayer.yaml]
name: first-rrelayer
description: 'my first rrelayer'
api_config:
  host: '0.0.0.0'
```

### port

The port the API will try to start up from

```yaml [rrelayer.yaml]
name: first-rrelayer
description: 'my first rrelayer'
api_config:
  port: 3000
```

When `unix_socket_path` is set, `host` and `port` are retained for configuration
compatibility but are not used to open a TCP listener.

### unix_socket_path - optional, Unix only

An absolute filesystem path for a Unix domain socket. This is useful when a
co-located process is the only component that should be able to reach rrelayer.
The socket is created with mode `0600` and removed on orderly server shutdown.

rrelayer refuses to overwrite regular files or an active socket at this path.
It replaces a socket only when the existing socket is stale and no longer
accepts connections. Parent directory ownership and permissions remain the
operator's responsibility; use an owner-only directory such as mode `0700`.

Requests over this transport have no TCP client IP. Network permission rules
that require an IP address therefore fail closed. Authentication and request
verification policies continue to apply normally.

```yaml [rrelayer.yaml]
api_config:
  port: 3000
  unix_socket_path: '/run/rrelayer/admin-broker.sock'
  authentication_username: "${RRELAYER_AUTH_USERNAME}"
  authentication_password: "${RRELAYER_AUTH_PASSWORD}"
```

### authentication_username

:::info
rrelayer users basic authentication for the API.
:::

The basic authentication username

```yaml [rrelayer.yaml]
name: first-rrelayer
description: "my first rrelayer"
api_config:
  port: 3000
  authentication_username: "${RRELAYER_AUTH_USERNAME}" // [!code focus]
```

### authentication_password

:::info
rrelayer users basic authentication for the API.
:::

The basic authentication password

```yaml [rrelayer.yaml]
name: first-rrelayer
description: "my first rrelayer"
api_config:
  port: 3000
  authentication_username: "${RRELAYER_AUTH_USERNAME}"
  authentication_password: "${RRELAYER_AUTH_PASSWORD}" // [!code focus]
```

### trust_forwarded_for - optional, defaults to false

When false, request IP policies use only the socket peer and ignore
`X-Forwarded-For`. This is the safe default. Enable it only behind an ingress
that overwrites client-supplied forwarding headers while preserving the real
source IP.

When enabled, a missing header falls back to the socket peer, a malformed or
non-ASCII header leaves the IP unresolved, and a multi-hop value uses only its
trimmed leftmost entry.

```yaml [rrelayer.yaml]
api_config:
  trust_forwarded_for: false
```
